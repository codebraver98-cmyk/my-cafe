# my-cafe
a website for a menu of a cafe where visitors can scan the QR code and navigate so they know what's on the menu then they can order whatever the want face to face or via social media. 
the main features of the website are the categories which take us to other detailed information
it's built so that the main file is the index.html inside it we have the home, the message and the menu then inside the menu we have 9 other folders that talk about categories for what we have in our cafe
it's easy to use and it guides the user on its own for when they open the homepage they directly press on the cart that would lead them to other portals and so on
